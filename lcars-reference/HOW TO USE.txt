====================================================
  J.A.R.V.I.S  -  UNIFIED APP ASSISTANT
====================================================

WHAT THIS IS
  One JARVIS that runs as a NATIVE APP window on a
  machine that has Python (Windows PC or Raspberry Pi)
  and is reachable from ANY other device (phone,
  Galaxy Watch 5, tablet, Pi 2) over your Wi-Fi.
  The AI lives in Ollama - on this machine OR another
  PC on your network.

START - as an APP (easiest way)
  Double-click:  C:\JARVIS\start_jarvis.bat
  A JARVIS app window opens (no browser, no URL).
  If pywebview is missing it gracefully opens the
  default browser instead - still fully working.

  From a terminal:
     cd C:\JARVIS
     run_jarvis.bat                 (app window)
     python run_jarvis.py           (app window)
     python run_jarvis.py --web     (serve web for other devices)

WAKE WORD  ("Hey JARVIS")
  Works out of the box if the machine running JARVIS
  has openwakeword + sounddevice (both already in
  .venv and wakeword_venv).
  To enable: in the app -> SYSTEM tab -> tick
  "Wake word (Hey JARVIS)" -> SAVE. Or check the box
  under the input bar (WAKE ARMED).
  When armed it listens for the phrase "Hey JARVIS";
  on hearing it, JARVIS turns its "ears" on for about
  6 seconds to catch your command (no constant mic).
  You can still tap the mic button anytime.

CONNECT FROM OTHER DEVICES (watch / phone / Pi 2)
  1. Run JARVIS in serve mode:
       python run_jarvis.py --web
  2. On the same network open a browser on the device and go to:
       http://<this-pc-ip>:8000
     run_jarvis.py prints the exact address.
  The watch / phone load the SAME movie UI - no install.

WHERE THE LLM (OLLAMA) LIVES
  Default is a local Ollama:  http://localhost:11434
  If Ollama runs on ANOTHER computer:
    1. On that PC expose Ollama to the network:
         setx OLLAMA_HOST "0.0.0.0:11434"   (Windows; restart Ollama)
       or:  OLLAMA_HOST=0.0.0.0:11434 ollama serve   (Linux/Pi)
    2. In JARVIS open SYSTEM and set the Ollama machine's address, e.g.
         http://192.168.1.50:11434
       then SAVE. No restart needed.
  Settings are stored in:  C:\JARVIS\config\config.json

MODEL
  Set in SYSTEM (default "qwen3:4b"). Pull it on the Ollama machine:
      ollama pull qwen3:4b

VOICE
  - Wake word arms "Hey JARVIS" (see above).
  - Mic button  : push-to-talk.
  - "Speak replies" turns on spoken answers (browser/watch TTS).

KITCHEN
  - SAVED tab : your recipes (create with + NEW).
  - WEB tab   : live search from TheMealDB.
  Recipes are stored in:  C:\JARVIS\server\kitchen\recipes.json

PI 2 NOTES
  The server is Python standard library only - a Raspberry Pi 2 can run it.
  For the APP window on Pi you'd use a lightweight backend; for simplicity
  run `python run_jarvis.py --web` there and open the UI in a browser, or
  `python run_jarvis.py` if a browser engine is available. Wake word uses
  openwakeword (armv7 wheel for onnxruntime) and will auto-enable if present.

FOLDERS
  server/          -> web server + wake word + kitchen engine
  server/static/   -> the movie-UI (drives the app window and the web page)
  server/desktop.py-> native app-window launcher (pywebview)
  server/wakeword.py -> "Hey JARVIS" detector
  config/          -> settings (config.json) + approved apps
  Old PySide6 code kept for reference: ai, core, tools, voice, ui, food.

STOP
  Close the JARVIS app window, or Ctrl+C in the console.
