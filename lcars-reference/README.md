# LCARS Reference Code

This folder is a staging area for reference code and snippets that will guide the JARVIS LCARS-style terminal redesign.

## How to use this folder

- Add the reference code you want JARVIS to be based on here.
- Keep any license or attribution information that came with the code.
- Treat these files as design/implementation references; the active app currently lives in \`static/index.html\`, \`static/style.css\`, and \`static/app.js\`.

The redesign should use the classic LCARS language: a black canvas, asymmetrical rounded panels, bold amber/orange and lavender blocks, compact technical readouts, and responsive layouts. Keep the existing local-model connection and approval-gated tools working.
